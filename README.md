To activate venv environment: source venv/bin/activate

To run: python app.py

To train Bert model: python train_albert_or_bert.py --model_name bert

To train AlBert model: python train_albert_or_bert.py --model_name albert

To train for certain epoch (example 20): python train_albert_or_bert.py --model_name albert --epochs 20

To train for certain epoch (example 50): python train_albert_or_bert.py --model_name albert --epochs 50
