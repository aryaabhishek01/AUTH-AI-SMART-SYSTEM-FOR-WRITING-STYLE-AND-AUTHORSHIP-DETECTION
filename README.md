To activate venv environment: venv\Scripts\activate

To run: python app.py

To train Bert model: python train.py --model_name bert 

To train AlBert model: python train.py --model_name albert 

To train for certain epoch (example 20): python train.py --model_name albert --epochs 20

To train for certain epoch (example 50): python train.py --model_name albert --epochs 50
